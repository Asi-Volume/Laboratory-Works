# Laboratory Works 6–10 — Food Construct

## Структура

- `index.html` — главная страница выбора лабораторной.
- `WEB6lab/` … `WEB10lab/` — пять самостоятельных проектов.
- Внутренние HTML/CSS/JS-файлы каждой лабораторной остаются в её папке.

## Локальный запуск

Откройте папку `Laboratory-Works` в редакторе и запустите локальный сервер (например, Live Server в VS Code). Затем откройте `index.html`. Для корректной работы `fetch` не рекомендуется открывать страницы напрямую через `file://`.

## Публикация на GitHub Pages

Загрузите содержимое всей папки `Laboratory-Works` в корень одного GitHub-репозитория. В настройках репозитория включите GitHub Pages для нужной ветки и корневой папки. Главная ссылка будет вести на `index.html`.

## Резервный API

В лабораторных 8–10 сначала выполняется запрос к API Мосполитеха. Если основной API недоступен, проект загружает рецепты через `GET https://dummyjson.com/recipes`. Для демонстрации создания/изменения/удаления заказов используются `POST /posts/add`, `PUT /posts/{id}` и `DELETE /posts/{id}` DummyJSON. DummyJSON возвращает имитацию успешных операций и не сохраняет изменения на своей стороне; поэтому демонстрационные заказы дополнительно сохраняются в `localStorage` конкретной лабораторной.

У лабораторных 8, 9 и 10 отдельные ключи `localStorage` (`lab8_…`, `lab9_…`, `lab10_…`), чтобы корзины и история не пересекались при размещении всех проектов на одном домене.

## Важно перед сдачей

Если преподаватель предоставит рабочий ключ API Мосполитеха, замените заглушку `ТВОЙ_UUID_КЛЮЧ_ЗДЕСЬ` / `КЛЮЧ` в соответствующих JS-файлах. Не публикуйте личный ключ в открытом репозитории, если это запрещено правилами курса.


## Обновление интерфейса меню

В разделах выбора блюд добавлены фильтры по макетам: супы, главные блюда и салаты — рыбные, мясные и вегетарианские; напитки — холодные и горячие; десерты — маленькая, средняя и большая порция. Повторное нажатие на активный фильтр снимает фильтрацию.

Главная страница выбора лабораторной упрощена: белый фон, краткое описание каждой работы и отдельная кнопка перехода.
